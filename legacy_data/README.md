# Временные legacy-данные

Этот каталог и загрузчик предназначены только для локального переходного
периода. `dev.sh` запускает `cmd/legacy-import` после старта PostgreSQL и до
старта основного backend. Импортер рассчитан не только на текущие две выгрузки:
каждый раздел оформляется независимым загрузчиком, а все загрузчики выполняются
в одной транзакции.

Загрузчик:

- читает продукты из `food.csv`;
- преобразует старый текстовый ключ продукта в стабильный UUID v5;
- читает вес из `weight.csv` и назначает его локальному development-пользователю;
- выполняет параметризованные UPSERT-запросы в одной транзакции, поэтому
  повторный запуск не создаёт дубликаты.

Для следующего раздела добавьте отдельный файл-загрузчик в
`internal/legacyimport` и зарегистрируйте его в `datasetLoaders` из
`importer.go`. Команду и `dev.sh` при этом менять не нужно. Если данные раздела
принадлежат пользователю, используйте `Config.UserID`, как это делает загрузчик
веса.

Когда импорт больше не понадобится, удалите каталоги `legacy_data`,
`cmd/legacy-import`, `internal/legacyimport`, помеченный блок `LEGACY IMPORT`
из `dev.sh` и помеченный абзац из корневого `README.md`. Основной backend от
этого механизма не зависит.
